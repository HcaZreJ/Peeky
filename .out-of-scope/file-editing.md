# 文件编辑

本项目不做编辑功能。定位是只读查看器。

## 原因

Peeky 的核心是快速冷启动打开文件预览（`peek <path>` 目标 time-to-window ≤ 450 ms）。编辑能力会引入保存、undo 栈、编码写回、文件权限、并发修改冲突检测一整条链路，与纯函数渲染管线 + 单一 UI 控制器的架构冲突，也会冲击冷启预算。

顺手改两行的需求由 **⌘E 用系统默认编辑器打开当前文件**（VS Code / Cursor 识别时带 `path:line` 行号定位）承接，实现见 plan `2026-07-03-peek-native.md` 单元 R4b。文本的**选中与复制**属于查看器应有能力，已在 R4a / R4b 覆盖。
